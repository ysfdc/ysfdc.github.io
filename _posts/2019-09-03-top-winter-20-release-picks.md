Here is a quick overview of the things I found most interesting coming in the Winter '20 release.

1. [Lightning is getting turned](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_lex_transition.htm) on for everyone that is using the standard profile or custom profiles that have the Lightning Enabled setting turned on
2. [New Mobile App on October 14th](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_mobile.htm) - time for the Mobile App to really sync with the Desktop App
3. [Recycling Bin for Lightning](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_lex_recycle_bin.htm) is finally here!
4. [Mass actions can now be performed on search results inside of a Listview](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_lex_lists_mass_actions.htm) - great for reducing the number of clicks!
5. [List view in Lightning are now printable](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_lex_lists_printable_view.htm) - great for exporting to PDF for someone external to review the information without creating a report
6. [Opportunity Contact Roles](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_opportunity_contact_roles_customize.htm) and [Account Teams](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_feature_core_accounts.htm) get a lot more flexible with customization now allowed
7. [Quote Lines](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_sort_quote_line_items.htm) and [Opportunity Products](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_features_core_products_sort.htm) can be finally be sorted any which way you want - just drag and drop!
8. [Pricebook Entries now support Audit trails and Field history tracking](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_features_core_pricebook_entries_track_changes.htm) - run reports on what has been changed when and by whom
9. [Related Contacts related lists finally get the Edit link](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_sales_features_core_account_contact_relationship_edit_action.htm) next to each record - no more clicking into the record to make changes
10. Ability to control the [visibility of Case Feed](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_chatter_set_post_visibility.htm) items in Lightning like you could in Classic - control Private vs Public based on each item
11. [Tabs and Accordion components](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_lab_tabset_on_home_pages.htm) can now be added to the Home Page
12. Better object limit breakdown on the [System Overview page](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_system_overview_objects.htm) - shows custom vs managed objects
13. [Durable Caching being added to Record pages](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_general_layout_refresh.htm) - this means that when you, the admin, make changes to a record page, it will take 15 minutes for you to see the change and an hour for your users to see the change
14. [Update to the DATEVALUE() function](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_datevalue_formula.htm) to handle Daylight Savings
15. GA: "[Where is this Used](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_fields_where_ga.htm)" button on fields :)
16. In Beta: [Permission Set Groups](https://releasenotes.docs.salesforce.com/en-us/winter20/release-notes/rn_forcecom_psg.htm) - have a set of Permission Sets that all go together? Now you can group them and just assign the group
