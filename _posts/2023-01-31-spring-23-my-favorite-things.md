While it does not seem like spring in most of the US, Salesforce releases do not seem to care. Our Spring release is just around the corner, and my goodness, it comes jam-packed with so many items that I couldn't just pick a few.

To keep this easy, I've separated them into categories and left you a small idea of what they are - the notes should give the rest. Anywhere you see an asterisk, I may write something about it in 2023.

Enjoy!

[Einstein Search](https://help.salesforce.com/s/articleView?id=release-notes.rn_search_ai_parent.htm&type=5&release=242):

- [Change your searchable fields by profile](https://help.salesforce.com/s/articleView?id=release-notes.rn_search_configure_manager.htm&type=5&release=242)

- [Configure searchable picklist](https://help.salesforce.com/s/articleView?id=release-notes.rn_search_searchable_picklist.htm&type=5&release=242) \- pick the values that you want to be searchable

- [Search manager](https://help.salesforce.com/s/articleView?id=release-notes.rn_search_learning_map.htm&type=5&release=242) - a central location in setup to control the personalization and search results

Page Layout Updates:

- Standard objects, including [Case and Leads](https://help.salesforce.com/s/articleView?id=release-notes.rn_lab_dynamic_form_enhancements.htm&type=5&release=242) finally have Dynamic Forms\*

- [Dynamic Actions](https://help.salesforce.com/s/articleView?id=release-notes.rn_lab_dynamic_actions_standard_objects.htm&type=5&release=242) now available on all of the Standard objects

- Include [Save buttons on Dynamic Forms](https://help.salesforce.com/s/articleView?id=release-notes.rn_lab_save_options.htm&type=5&release=242) adding greater control to the layout

- Make [custom forecast page](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_features_core_forecasting_custom_pages.htm&type=5&release=242) when using collaborative forecast

- Be able to see the full list of records in a [Dynamic Related List](https://help.salesforce.com/s/articleView?id=release-notes.rn_lab_dynamic_related_list_view_all.htm&type=5&release=242)

- Add [pinned sections](https://help.salesforce.com/s/articleView?id=release-notes.rn_pin_important_content_on_the_right_side_of_record_pages.htm&type=5&release=242) to record layouts

Permission Updates

- Add the field level security to permission sets when creating new fields

- [User Access Policies](https://help.salesforce.com/s/articleView?id=release-notes.rn_permissions_access_user_access_policies.htm&type=5&release=242) \- this might be my favorite thing - ability to create automatic additions of permission sets with clicks not code\*

Sales Cloud

- Coming soon... Ability to [add opportunity splits](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_features_core_product_splits_pilot.htm&type=5&release=242) to opportunity products

- [Updated Actions](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_productivity_activity_composer.htm&type=5&release=242) when working with Activities on the page layout (I really like how this look)\*

- Users can now define their [email preferences](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_productivity_email_settings.htm&type=5&release=242) right from the Activity tab

- When sending an email from Salesforce you can let the [customer pick their own meeting times](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_productivity_inbox_choose_meeting_times_child.htm&type=5&release=242)

- The migration from [Lightning Sync](https://sf9to5.com/2018/10/23/lightning-outlook-lightning-sync-inbox/) to [Einstein Activity Capture](https://help.salesforce.com/s/articleView?id=release-notes.rn_sales_lightning_sync_google_walkthrough.htm&type=5&release=242) is almost complete - make sure to check out the last remaining steps

Misc Items

- You can now [track field history](https://help.salesforce.com/s/articleView?id=release-notes.rn_customization_activity_field_history.htm&type=5&release=242) for Activities (please be careful with this)

- Better ways to [clean up](https://help.salesforce.com/s/articleView?id=release-notes.rn_fields_picklist_delete_inactive_values_ga.htm&type=5&release=242) and [modify picklist](https://help.salesforce.com/s/articleView?id=release-notes.rn_fields_bulk_manage_picklist_values_ga.htm&type=5&release=242) values in bulk

- [Scale Center](https://help.salesforce.com/s/articleView?id=release-notes.rn_scalecenter.htm&type=5&release=242) - currently in Beta, but should help when trying to analyze how the system is running
